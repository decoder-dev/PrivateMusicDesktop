# Проверки интерфейса

Настоящий интерфейс запускается в Chromium с тестовой реализацией команд
`mock-backend.js` и той же политикой Content-Security-Policy, что у приложения.

```sh
npm install && npx playwright install chromium  # первоначальная подготовка
npm test
PM_SCREENSHOTS=/tmp/shots npm test               # сохранение снимков экрана
```

Обычно включено уменьшение движения: изменения состояния происходят сразу,
без ожидания анимаций. Проверки движения, размытия и визуализации развёрнутого
плеера самостоятельно выбирают `no-preference` через `motionApp` в `ui.test.js`.
