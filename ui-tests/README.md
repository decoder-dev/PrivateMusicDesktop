# Проверки интерфейса

Настоящий интерфейс запускается в Chromium с тестовой реализацией команд
`mock-backend.js` и той же политикой Content-Security-Policy, что у приложения.

```sh
npm install && npx playwright install chromium  # первоначальная подготовка
npm test
PM_SCREENSHOTS=/tmp/shots npm test               # сохранение снимков экрана
```

Обычно включено уменьшение движения: изменения состояния происходят сразу,
без ожидания анимаций. Проверки движения, размытия и визуализации развёрнутого
плеера самостоятельно выбирают `no-preference` через `motionApp` в `ui.test.js`.

## Телефонная раскладка

`phone.test.js` открывает приложение так, как его видит WebView Android: касания, мобильное окно
и пользовательский агент Android (`openApp({ phone: true | "small" | "large" | "landscape" })`,
`config.platform: "android"` в ответе `app_info`). Помимо сценариев жестов, возврата, листов, умных
плейлистов, массовых действий и входа он содержит проверки по всем экранам: цели нажатия не меньше
44 px, нет элементов только для наведения, нет горизонтального переполнения на 360, 412, 430 px и в
альбомной ориентации, учтены безопасные зоны и уменьшение движения.
