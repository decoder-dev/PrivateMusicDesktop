# Private Music 1.0.1

Исправительный выпуск Compose Multiplatform.

## Исправлено

- Команды воспроизведения теперь отправляют все обязательные поля Rust, включая `is_hq`; исправлена ошибка `missing field is_hq` при нажатии на трек.
- Чтение состояния плеера выполняет ровно один FFI‑запрос; ответ Rust больше не отправляется повторно как команда.
- Главная и очередь больше не показывают демонстрационные треки в production без входа в VK.
- Ошибки загрузки каталога отображаются на главной, в поиске, миксах, загрузках и текстах песен.
- Проверена загрузка упакованной Rust‑библиотеки из desktop‑ресурсов.
- Windows MSI теперь создаёт собственные ярлыки Start Menu/Desktop и использует постоянный `upgradeUuid` для обновления.

Если системный ярлык «Private Music» продолжает открывать старый Tauri из `AppData\Local\Private Music`, удалите прежнюю Tauri‑версию через «Установленные приложения» и используйте ярлык нового MSI. Удаление старой версии не требуется для запуска `C:\Program Files\PrivateMusic\PrivateMusic.exe` напрямую.

Пакеты и контрольные суммы подписаны именами версии `1.0.1`. Android сохраняет прежний `applicationId`; `versionCode` увеличен до `10001`.
