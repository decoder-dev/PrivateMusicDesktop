## Что изменилось

Внешний вид:

- По умолчанию включена «Тихая сцена»: тёплый фон, наборные заголовки, сплошные меню, диалоги, листы, тосты и карточка входа. Классический вид, прежний основной и Material 3 остаются в настройках.
- Телефон и компьютер используют одни и те же цвета в светлой и тёмной теме. Док и мини-плеер больше не стеклянные.

Язык:

- В оформлении можно выбрать русский, английский или язык системы. Окно перезапускается, и строки, включая тексты песен и умные плейлисты, собираются заново.

Сеть:

- Каталожные запросы к VK идут не больше чем по два сразу, чтобы старт и возврат в приложение не устраивали очередь из библиотеки, полок и истории одновременно.
- Команды воспроизведения этот предел не ждут. Ограничение по `Retry-After` и хранение токена в системном хранилище не менялись. Капча по-прежнему решается на странице входа VK.

Надёжность предыдущих правок, которые входят в этот выпуск вместе с оформлением: позиция прокрутки списков сохраняется, очередь с радио восстанавливается после перезапуска, а установщики публикуются даже без ключа встроенного обновления.

## Проверки

- Интерфейсные тесты на Linux в Chromium, включая телефонную вёрстку и предел каталожных запросов.
- Сборки Windows, macOS и Android выполняются в GitHub Actions по этому тегу. В этой среде они не запускались.

## Установка

Выберите APK для Android ARM64, установщик Windows x64, универсальный DMG для macOS или AppImage/DEB для Linux x64. Если в репозитории заданы секреты `ANDROID_KEYSTORE_*`, APK подписывается постоянным ключом и ставится поверх прошлой версии. Если их нет, APK подписывается отладочным ключом, и это будет сказано ниже. Встроенное обновление компьютера работает только при ключе `TAURI_SIGNING_PRIVATE_KEY`; иначе ставьте новый установщик вручную.
