## Что исправлено

- «Следующий» в конце радио теперь ожидает догрузку из выбранного источника. Если первый раунд не удался или вернул только повторы, используются оставшиеся попытки, а не преждевременная остановка. Лимит запросов сохраняется.
- Пауза, в том числе из системного уведомления, во время загрузки и догрузки отменяет ожидающий переход: поздний ответ больше не запускает музыку сам.
- Кнопка перехода в обычной конечной очереди доступна только при наличии следующего трека. Это учитывает реальный порядок перемешивания и повтор всей очереди; состояние передаётся в мини-плеер и системное уведомление Android.
- Исправлена гонка между временной потерей аудиофокуса, его возвращением и подтверждением паузы. Возобновление ждёт обработки паузы. Кнопки громкости Android явно направлены на громкость музыки.
- Диагностический отчёт показывает память и различает обновление приложения, системное завершение и другие причины выхода. Для системных команд плеера записывается причина без названий треков и личных данных.

## Проверки и ограничения

Добавлены проверки конца радио, повторов догрузки, паузы при незавершённом запросе, порядка команд аудиофокуса и доступности кнопок. Проверки запуска Android выполняются на API 34 и 36.

Изменения проверяют конкретные ошибки управления воспроизведением. Исходный HONOR для замеров недоступен; устранение всех задержек и причины реакции именно этого устройства на кнопки громкости пока не подтверждены.

APK сохраняет ключ подписи предыдущих версий. Для iOS используется отдельный репозиторий и выпуск PrivateMusic2.
