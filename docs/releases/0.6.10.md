## Что изменилось

- Медиатека сохраняет позицию прокрутки после завершения фоновой загрузки треков.
- В Linux исправлена ошибка работы с памятью в GLib, способная приводить к падению приложения.
- Исправлена генерация идентификаторов воспроизведения.
- Обновлены совместимые зависимости Rust и инструменты Android-сборки. Устранены уязвимые вложенные библиотеки; свежая проверка GitHub не показывает открытых предупреждений Dependabot и Code scanning.
- Расширены проверки интерфейса, Android-плагинов, обновления поверх предыдущей версии и пакетов для компьютера.
