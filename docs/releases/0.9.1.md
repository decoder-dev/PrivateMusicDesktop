## Что исправлено

Поиск:

- Подсказка «Введите запрос, чтобы найти музыку» с иконкой видна сразу при открытии вкладки. Раньше она появлялась только после перехода на «Тексты» и обратно.
- На телефоне результаты снова подгружаются при прокрутке: раньше список обрывался на первых 50 треках.
- «Вы искали» хранит запросы, с которыми вы что-то сделали: нажали Enter, включили трек, открыли исполнителя или альбом. Недопечатанные варианты («кин» перед «кино») больше не попадают в историю.
- Enter на телефоне убирает клавиатуру, чтобы результаты было видно.
- Возврат из «Текстов» к трекам больше не запускает поиск заново и не сбрасывает уже подгруженные результаты.
- Когда есть недавние запросы, подсказка «Введите запрос» под ними не повторяется.

## Проверки

- 381 UI-тест, включая новые проверки поиска на телефоне и на ПК.
- Сборка и запуск на Linux, Windows и macOS; эмулятор Android (API 34 и 36).

## Установка

Выберите APK для Android ARM64, установщик Windows x64, универсальный DMG для macOS или AppImage/DEB для Linux x64. APK подписывается постоянным ключом приложения, а пакеты обновления ПК — ключом обновлений. Установщики Windows и macOS пока без сертификата доверенного издателя/нотариализации.
