## Что нового

- **Material 3 на всех устройствах.** В настройках «Вид приложения» теперь есть на ПК и на Android: «Стандартный» или «Material 3». Material 3 даёт тональные цвета от акцента, навигационную панель и боковое меню, кнопки-«пилюли», поля, сегментные вкладки, переключатели, меню, диалоги, плеер и снэкбары в стиле Android. В тёмной теме страница и верхняя панель используют одну тональную поверхность.
- **Фильтры в библиотеке** сначала ищут точную фразу, затем слова в любом порядке по названию и исполнителю: «кино группа» находит «Кино — Группа крови».

## Что исправлено

- Android: часы и значки статус-бара следуют теме приложения. Раньше при тёмной теме в приложении и светлой системе они оставались тёмными на тёмном фоне (и наоборот).
- Android: ползунки эквалайзера снова вертикальные на системных WebView старше Chrome 124; полоса частот больше не показывает лишнюю полосу прокрутки.
- Мини-плеер: у трека без обложки показывается значок ноты, а не пустой квадрат.
- Медиатека: плейлисты без обложки выравниваются по остальным, а не сдвигаются к краю.
- Загрузки: переключатель «Удалять ушедшие из подборки файлы» стоит рядом со своим текстом на телефоне.
- Экран входа целиком помещается в горизонтальной ориентации телефона.
- Linux: устранено аварийное завершение в GLib при уничтожении главного цикла раньше отложенной задачи.
- Безопасность зависимостей: модуль обновлений ПК переведён на zip 9 (RUSTSEC-2026-0429 и три более ранних уведомления zip), аудиобуфер — на ringbuf 0.5.3 (RUSTSEC-2026-0293). Политика `cargo audit` больше не содержит исключений.
- Список сохранённых загрузок в локальном хранилище ограничен по размеру.

## Проверки

- Эмулятор Android (API 34 и 36) проходит реальное воспроизведение, вход VK, Keystore, обновление поверх старой версии и визуальный обход всех экранов в стандартном стиле и в Material 3 со скриншотами с устройства; отдельный шаг проверяет цвет значков статус-бара.
- 371 UI-тест, сборка и запуск на Linux, Windows и macOS.

## Установка

Выберите APK для Android ARM64, установщик Windows x64, универсальный DMG для macOS или AppImage/DEB для Linux x64. APK подписывается постоянным ключом приложения, а пакеты обновления ПК — ключом обновлений. Установщики Windows и macOS пока без сертификата доверенного издателя/нотариализации.
