# Private Music 1.0.2

- Новый интерфейс Compose с нижней навигацией на телефоне и боковой в широком окне. Плеер, очередь, поиск и загрузки оформлены в одной теме и показывают обложки из каталога, когда они доступны.
- Исправлена обработка ответов движка для каталога, миксов, загрузок и управления плеером.
- Исправлена передача кириллицы и других символов между плеером и движком на компьютере.
- Результаты поиска больше не заменяют рекомендации на главной. Миксы повторяют запрос при отклонённых настройках и сохраняют очередь, если треков нет.
- Скрипты установки поддерживают Windows MSI и отдельные пакеты macOS для Intel и Apple Silicon.
- DEB устанавливается на чистой системе, где ещё не созданы каталоги меню приложений.
- Исправлен запуск Android-приложения и инициализация звукового движка.
