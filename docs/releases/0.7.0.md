## Что изменилось

- Добавлен раздел «На устройстве»: импорт MP3, M4A, AAC, WAV и FLAC через системный выбор файлов. Приложение проверяет содержимое, читает название и исполнителя и сохраняет собственную копию. Повторный импорт одинакового файла не создаёт дубликат.
- Локальные треки воспроизводятся в общей очереди без обращения к VK. Они не отправляются в статус, историю прослушивания VK или рекомендации; сетевые действия скрыты. Удаление из локальной библиотеки сохраняет исходный файл.
- На телефоне свайп по обложке переключает трек, жест вверх открывает очередь. Свайп назад выбирает предыдущую композицию даже после нескольких секунд воспроизведения; кнопка «Назад» сохраняет привычный перезапуск текущего трека.
- В меню трека добавлено копирование названия и исполнителя.
- Устаревшие задания загрузки обложек Android отбрасываются перед сетевым запросом, переходом по перенаправлению и декодированием изображения.

Импорт: до 100 файлов за один выбор, до 150 МБ каждый. Файлы с защитой или неподдерживаемым кодеком внутри контейнера не импортируются; приложение показывает список ошибок. Обложки из тегов локальных файлов пока не извлекаются.

## Установка

Выберите APK для Android ARM64, установщик Windows x64, универсальный DMG для macOS или AppImage/DEB для Linux x64. APK подписывается постоянным ключом приложения, а пакеты обновления ПК — ключом обновлений. Установщики Windows и macOS пока без сертификата доверенного издателя/нотариализации.
