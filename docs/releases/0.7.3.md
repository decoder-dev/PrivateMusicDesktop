## Что исправлено

- Зарегистрирован no-op media-session plugin на настольных платформах и iOS. При запуске UI отправляет настройки воспроизведения; раньше отсутствие плагина вызывало panic в фоновом потоке на desktop.

## Проверки

- Запуск приложения на Linux, Windows и macOS проверяется в release workflow вместе с UI-check и проверкой подписанных пакетов.
