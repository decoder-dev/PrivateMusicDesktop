# Private Music 1.0.0

Первый выпуск на **Kotlin + Compose Multiplatform** с сохранённым Rust‑ядром воспроизведения. Браузерный JavaScript больше не используется для интерфейса нового приложения.

## Что нового

- Общий нативный Compose‑интерфейс для Android и desktop.
- Главная, очередь, мини‑плеер и полноэкранный плеер.
- Вход в VK, библиотека, поиск, рекомендации, миксы, радио и новые релизы.
- Загрузки, офлайн‑библиотека и тексты песен.
- Android‑уведомление с обложкой, прогрессом, перемоткой и системными кнопками воспроизведения.
- Мультимедийные клавиши Windows.
- Rust подключён через JNI на Android и JNA на desktop; нативная библиотека входит в установочные пакеты.

## Пакеты

- Windows x64: MSI.
- Linux x64: DEB.
- macOS Intel и Apple Silicon: отдельные DMG.
- Android arm64: APK с тем же `applicationId`, что у прежних выпусков, поэтому установка возможна поверх совместимо подписанной версии.

Контрольные суммы всех файлов находятся в `SHA256SUMS.txt`.

## Проверки

В CI выполняются Rust‑сборка, общие и визуальные Compose‑тесты, проверка загрузки Rust из desktop‑ресурсов, сборка четырёх desktop‑пакетов и подписанного Android APK. Живой VK‑аккаунт и физические устройства в автоматических проверках не используются.
